Qué hace cada tecnología

Si estás empezando, es normal preguntarte si HTML, CSS y JavaScript son tres formas distintas de hacer lo mismo. En realidad, cada uno resuelve una parte de la página. Separarlos ayuda a encontrar errores y cambiar una cosa sin rehacer todo el proyecto.

HTML: la estructura y el significado

HTML organiza el contenido: títulos, párrafos, enlaces, imágenes y botones. Una etiqueta como <h1> identifica el encabezado principal; <button> crea un botón. El navegador puede mostrar esta estructura aunque todavía no hayas añadido estilos o programación.

Usar la etiqueta adecuada también ayuda a quienes navegan con teclado o lector de pantalla. Un botón real ya tiene comportamientos que no obtienes simplemente dibujando un rectángulo. Profundiza en HTML semántico y la elección de etiquetas según su función.

CSS: la presentación

CSS indica cómo se ve el contenido: colores, tamaños, separación y distribución. Por ejemplo, una regla para body puede cambiar el fondo de toda la página. CSS selecciona elementos del HTML y les aplica propiedades; no necesita JavaScript para funcionar. Para distribuir grupos de elementos, continúa con Flexbox CSS y sus ejemplos de tarjetas adaptables.

JavaScript: el comportamiento

JavaScript permite responder a acciones. En este ejercicio detectará un clic y cambiará un mensaje. No construirá toda la página ni decidirá sus colores: añadirá una interacción a una estructura que ya existe. El DOM de JavaScript permite consultar y modificar esa estructura en memoria.

Idea clave

HTML define la estructura, CSS controla la presentación y JavaScript añade comportamiento. Si falla una conexión, revisa esa parte sin asumir que las otras dos también están mal.

Estructura básica del proyecto

Crea una carpeta llamada mi-proyecto y, dentro, tres archivos. Puedes usar un editor de texto o código; lo importante es guardarlos con los nombres y extensiones correctos.

index.html será el punto de entrada. styles.css guardará las reglas visuales y script.js, la interacción. No necesitas instalar un framework, crear una cuenta ni usar un sistema de compilación para este ejemplo.

Comprueba que tu editor no haya añadido una extensión oculta: styles.css.txt no es el mismo nombre que styles.css. Mantén los tres archivos en la misma carpeta durante este primer ejercicio.

Una ruta relativa se interpreta desde el archivo que hace la referencia. Como aquí HTML, CSS y JS están juntos, basta escribir el nombre de cada archivo. Más adelante, si mueves CSS a una carpeta css, el enlace desde HTML deberá usar css/styles.css.

Cómo conectar CSS con HTML

Dentro de <head>, añade esta línea. El head contiene información y referencias de la página; no es donde escribes los párrafos que leerá una persona.

rel="stylesheet" identifica el recurso como hoja de estilos y href="styles.css" indica dónde está. El navegador solicita ese archivo y aplica sus reglas al HTML. La etiqueta link no necesita etiqueta de cierre.

El nombre del archivo no activa los estilos por sí solo: tiene que coincidir con la ruta de href. Si escribiste estilos.css al guardarlo, cambia el enlace o renombra el archivo. No copies CSS dentro de la etiqueta; el contenido de la hoja va en styles.css.

Para comprobar esta conexión, empieza con un cambio fácil de reconocer, como el fondo. Si el fondo cambia al recargar, ya tienes una señal concreta de que la hoja está llegando a la página.

Cómo conectar JavaScript con HTML

En el mismo <head>, enlaza el archivo JavaScript. A diferencia de link, script sí lleva cierre, incluso cuando su contenido está en otro archivo.

src apunta al archivo. Para un script externo clásico, defer permite descargarlo mientras el navegador sigue interpretando HTML y lo ejecuta después de terminar ese análisis. Así el botón ya existe cuando nuestro código lo busca. Además, los scripts clásicos con defer respetan el orden en que aparecen.

Sin defer, un script clásico en el head detiene el análisis de HTML mientras se descarga y ejecuta. Si busca un botón situado más abajo, puede encontrar null, porque el navegador todavía no ha creado ese elemento.

Ejemplo completo: un botón que saluda

Ahora completa los tres archivos. Copia cada bloque en el archivo que indica su encabezado. No pegues las etiquetas <script> dentro de script.js, ni las etiquetas <style> dentro de styles.css.

1. El contenido de index.html

El lang="es-MX" indica el idioma del documento, charset permite interpretar caracteres como tildes y signos, y viewport ayuda a mostrar la página correctamente en pantallas móviles. El título del head aparece en la pestaña; el h1 está dentro de la página.

Los identificadores saludar y mensaje permiten localizar dos elementos concretos. El párrafo empieza vacío porque recibirá el saludo. Su role="status" ayuda a anunciar ese cambio sin mover el foco.

2. La presentación en styles.css

Cada regla tiene un selector, como body o button, y propiedades entre llaves. El fondo permite comprobar que CSS está conectado. El estilo de foco mantiene visible qué control estás usando al navegar con Tab.

3. La interacción en script.js

document.querySelector busca un elemento del documento. El símbolo # significa que buscamos por ID: #saludar corresponde al botón con id="saludar".

addEventListener registra una acción para el evento click. La función escrita como () => { ... } se ejecuta cuando ocurre ese evento, no al registrarse. Dentro, textContent cambia el texto del párrafo seleccionado. No hace falta recargar para ver el saludo.

El botón seguirá siendo un botón aunque JS esté desactivado; lo que dependerá del script será actualizar el mensaje. Esta diferencia ayuda a distinguir contenido de comportamiento.

Cómo comprobar que todo funciona

  1. Guarda los tres archivos. Los cambios sin guardar no llegan al navegador.
  2. Abre index.html en el navegador. Este ejemplo no utiliza módulos ni fetch, así que puedes probarlo directamente como archivo local.
  3. Comprueba que aparecen el título y el botón: esa es la estructura HTML.
  4. Busca el fondo lavanda y el botón oscuro: son señales de CSS.
  5. Haz clic en Saludar y revisa que aparece el mensaje: esa es la interacción de JavaScript.
  6. Recarga después de cambiar un archivo y vuelve a probar.

También puedes servir la carpeta con python -m http.server 8000 si ya tienes Python y abrir la dirección local que indica el servidor. El blog Bitácora Stack sí usa módulos y catálogos JSON, por lo que conviene ejecutarlo con servidor local, como explica su README.

Si algo falla, abre las herramientas de desarrollo del navegador y revisa Console y Network. Una petición fallida a styles.css o script.js apunta a una ruta; un error dentro del script apunta a su código. Verifica una conexión a la vez.

Errores comunes y cómo encontrarlos

  • Nombre o ruta distintos. styles.css y style.css son archivos diferentes. Comprueba cada letra, extensión y carpeta.
  • Mayúsculas inconsistentes. Una ruta que parece funcionar en tu equipo puede fallar en un servidor que distinga mayúsculas. Usa nombres en minúsculas y enlaces que coincidan exactamente.
  • Un ID que no coincide. Buscar #saludo no encuentra id="saludar". Compara el selector con el HTML.
  • JS ejecutado demasiado pronto. Si el elemento es null, revisa su ID y la posición o carga del script antes de cambiar toda la lógica.
  • Archivos sin guardar o versión anterior. Guarda, recarga y comprueba en Network qué archivo recibió el navegador.

Error común

Escribir correctamente el nombre del archivo pero utilizar una ruta equivocada. Si CSS está dentro de otra carpeta, el enlace debe indicar esa carpeta desde la ubicación del HTML.

No añadas una barra inicial por costumbre: /styles.css busca desde la raíz del sitio, mientras que styles.css parte de la carpeta actual. En un proyecto alojado dentro de un repositorio esa diferencia puede romper la conexión.

Pruébalo tú mismo

Pruébalo tú mismo

  1. Cambia el título visible desde HTML.
  2. Cambia el fondo desde CSS, conservando texto legible.
  3. Cambia el saludo desde JavaScript.
  4. Mueve styles.css a una carpeta css y corrige el href.

Antes de recargar, predice qué debería cambiar. Después comprueba si ocurrió. Si un cambio falla, revisa primero el archivo responsable y su conexión.

Como comprobación adicional, navega hasta Saludar con Tab y actívalo con Enter o Espacio. Debes poder utilizar el ejemplo sin depender del mouse.

Lo que debes recordar

Lo que debes recordar

  • HTML organiza el contenido y le da significado.
  • CSS presenta ese contenido; no depende de JavaScript.
  • JavaScript responde a eventos y modifica la página.
  • href enlaza CSS y src enlaza el script externo.
  • Las rutas se interpretan desde el archivo que referencia el recurso.
  • Para este ejemplo, un script externo con defer evita buscar elementos antes de que existan.

Con estas tres conexiones funcionando tienes una base pequeña, pero completa. El siguiente paso no es añadir muchas herramientas: es hacer un cambio concreto en cada archivo y entender su efecto.
