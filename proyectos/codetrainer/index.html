Proyecto / Desarrollo móvil

CodeTrainer

Aplicación móvil orientada a estudiantes que desean practicar programación, recibir retroalimentación y seguir su progreso.

En desarrolloKotlinAndroid

Practicar para aprender.

CodeTrainer es un proyecto de aplicación móvil educativa orientado a practicar programación, recibir retroalimentación y dar seguimiento al progreso.

La propuesta tecnológica contempla Kotlin, Android y persistencia local. Esta ficha describe su enfoque; los detalles de implementación se incorporarán conforme estén confirmados.

El problema que aborda

Aprender programación requiere oportunidades para practicar y revisar lo que se ha comprendido. CodeTrainer se orienta a esa práctica desde una aplicación educativa.

Enfoque y objetivo

Reunir práctica de programación, retroalimentación y seguimiento del progreso en una experiencia móvil para estudiantes.

Áreas de trabajo

  • Programación con Kotlin.
  • Desarrollo de aplicaciones para Android.
  • Persistencia local.
  • Software educativo orientado a la práctica.

El proyecto sigue en desarrollo. Esta página se ampliará con decisiones de arquitectura y aprendizajes documentados cuando estén disponibles.
